## اصل کلی

**قبل از ارتقا، از نسخهٔ فعلی پشتیبان JSON بگیرید.** ارتقا نباید داده را حذف کند.

## چه چیزی منتقل می‌شود؟

- پیشرفت فیزیک، پروفایل، تنظیمات، برنامه و تاریخچهٔ مطالعه
- دادهٔ روتین و بایت فایل‌های پیوست (در پشتیبان یکپارچهٔ نسخهٔ ۸۰)
- پشتیبان‌های قدیمی فیزیک/روتین نیز پذیرفته می‌شوند.
